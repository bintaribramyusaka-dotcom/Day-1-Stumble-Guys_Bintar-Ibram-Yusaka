## Repository
Sebuah repositori GitHub (sering disebut repo) adalah ruang penyimpanan digital tempat seluruh berkas proyek, kode sumber (source code), dokumentasi, dan catatan riwayat perubahan (version history) dari suatu proyek disimpan dan dikelola menggunakan sistem kontrol versi Git..

## Tujuan kegunaan
Tujuan utama repositori GitHub:
1.Melacak Perubahan: Menyimpan riwayat revisi kode agar bisa dikembalikan ke versi sebelumnya jika terjadi eror.
2.Kolaborasi Tim: Memungkinkan banyak orang bekerja pada proyek yang sama secara bersamaan tanpa saling menimpa kode.
3.Cadangan Aman (Cloud): Menyimpan kode di internet sebagai backup dari perangkat lokal.
4.Portofolio: Memamerkan hasil proyek dan kemampuan coding kepada rekruter atau publik.

## Ringkasan Materi
Prompt Engineering: Mempelajari cara merancang instruksi prompt yang spesifik dan efektif kepada AI menggunakan struktur yang baik Role, Task, Context, Constraints, Format untuk menghasilkan kode aplikasi yang akurat.

Git & GitHub Basics: Mengenal perbedaan antara Git sistem kontrol versi lokal dan GitHub platform web untuk penyimpanan repositori online.

Memahami alur kerja Git Working Directory Staging Area Local Repository. Mempraktikkan perintah esensial Git seperti git init, git add, git commit, git remote add, dan git push.
